# 历史记录

本目录保存旧版本、修复中间状态和无效的裁判尝试。本目录只供追溯，不是当前的评分入口。当前状态见任务目录的 `delivery_note.md`。

| 位置 | 内容 |
|---|---|
| `package_root/交付文档.md` | 原来的外层交付说明，原文保存。 |
| `CHANGELOG.md` | 原来 `delivery_note.md` 的全文，以及之后每次修改的记录。早期章节中有后来撤回的暂定分数。 |
| `*.v1.*` | 2026-10-23 交付时的版本，原字节保存。 |
| `*.round1.*`、`*.round2.*`、`*.round3.*`、`*.pre_judge_fix.*` | 评分器 v2 修复过程中的中间状态。部分离线操作发生在 2026-10-25。文件上的版本日期不是运行日期。 |
| `golden/`、`rollouts/`、`judge_runs/` | 评分备份、原始裁判输出、重评记录和各轮尝试，按原目录层级保存。无效的裁判尝试不是分数，不进入成绩和一致性统计。 |
| `validation/` | 旧的离线输出、检查记录、基线、旧脚本和读取校验样例。旧脚本只供追溯。当前的检查入口是任务目录的 `validation/run_regression.py`。 |
| 本目录的裁判汇总、费用记录和排除记录 | 按当时的记录保存。账户余额的变化不是单次请求的账单。 |
| `before_cleanup/` | 整理目录前的文件原文，以及拆分前的正负例说明。 |
| `manifests/` | 整理前的两份文件清单快照。它们只记录旧目录，不是当前清单。 |

搬到本目录的文件保留了原来的相对路径。历史文档和旧脚本中的路径必须按搬移前的布局理解。当前的 `manifest.json` 覆盖本目录的全部文件。
