# 历史记录

这里存放旧版本、修复过程中的中间状态和无效的裁判尝试，只供追溯，不是当前的评分入口。当前状态看任务目录下的 `delivery_note.md` 和当前的评分记录。

| 位置 | 内容 |
|---|---|
| `package_root/交付文档.md` | 原来的外层交付说明，原文保留。现在的外层说明只指向当前状态。 |
| `CHANGELOG.md` | 原来 `delivery_note.md` 的全文，以及之后每次修改的记录。早期章节里可能有后来撤回的暂定分数。 |
| `*.v1.*` | 2026-10-23 交付时的版本，原字节保留。 |
| `*.round1.*`、`*.round2.*`、`*.round3.*`、`*.pre_judge_fix.*` | 2026-10-26 评分器 v2 修复过程中的中间状态。部分离线操作实际发生在 2026-10-25，文件上的版本日期不等于运行日期。 |
| `golden/`、`rollouts/`、`judge_runs/` | 按原来的目录层级保留的评分备份、原始裁判输出、重判和各轮尝试。无效的裁判尝试不是分数，占位的 0 分不进成绩，也不进一致性统计。 |
| `validation/` | 旧的离线中间输出、检查记录、基线、旧脚本和读取校验用的样例。旧脚本只供追溯，现在统一用任务目录下的 `validation/run_regression.py`。 |
| 本目录下的裁判汇总、费用和排除记录 | 按当时的观察保留。账户余额的变化不当作单次请求的账单。 |
| `before_cleanup/` | 整理目录时改过引用或合并过内容的文件原文，以及拆分前完整的正负例说明。 |
| `manifests/` | 整理前的两份文件清单快照，只记录旧目录，不是当前清单。 |

搬过来的文件都保留了原来的相对路径，所以历史文档和旧脚本里的路径要按搬移前的布局理解。旧脚本的回归检查都已经并进现在的检查入口。当前的 `manifest.json` 覆盖本目录的全部文件。
