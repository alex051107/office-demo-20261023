# 评分说明

评分器版本是 v2（2026-10-26）。本题有 13 条判据：

- 3 条程序正项：R01–R03，每条 10 分，合计 30 分。
- 7 条程序负项：S01–S06 和 P01，每条 −3。
- 3 条 LLM 负项：L01–L03，每条 −3。

## 术语

- **答卷**：模型交出的 `answer.xlsx`。
- **参考答案**：出题方写的标准答卷。
- **判据**：一条评分规则。程序判据由脚本检查。LLM 判据由裁判检查。
- **裁判**：执行 LLM 判据的模型。

## 表头和多加的列

- 题面只规定 Results 的 `A1:D1` 四个表头。题面没有规定整张表只能有四列。
- 答卷可以在后面加列，可以加空白的样式列，也可以加辅助表。
- 评分器比较表头时，先去掉首尾空格。大小写和顺序必须一致。
- 评分器不按表头到别的表里找答案。Results 缺失或名字不对时，总分是 0。

## 整卷 0 分和封顶

评分器先合成正负项分数，再套用以下两条规则。规则不进分母。触发的规则和原因写在 `reward-details.json` 的 `score_policy` 中。

| 规则 | 触发条件 | 总分上限 |
|---|---|---:|
| `required_sheet_gate` | Results 缺失或名字不对 | 0 |
| `must_clause_cap` | 表头不对；必需结果的来源为空或只有数字；单位不对；Results 多出带业务值、标签不在必需列表中的记录 | 0.69 |

- 行序、重复的必需行和小数位只扣分，不封顶。
- 只有文字、没有业务值的备注行不算多出的记录。
- 辅助表不受 Results 结构的限制。
- 评分器按题面固定的 A、B 两列读取数值。答卷只调换表头、没有改数据时，数值判据仍得分，然后总分封顶到 0.69。

## 小数位

题面要求三位小数。以下任一条件满足时，小数位合格：

- 单元格格式显示三位小数。
- 存储值等于四舍五入到三位的值。

题面写“至少 p 位”时，存储值的小数位不少于 p 也合格。这条规则只检查小数位，不放宽数值准确性。

## 数值容差

- 直接摘录的数值，容差是 0.0005 AUD million。
- 三个结果都是汇总值。先把每类资产的差额舍入到三位再相加，这是等价算法。这个算法会累积舍入误差。
- 网络类和非网络类各有 3 项非零差额。最大误差是 3 × 0.0005 = 0.0015。
- 全部资产有 7 项非零差额，另外 5 项正好是 0。最大误差是 7 × 0.0005 = 0.0035。
- 所以 R01、R02 的容差是 0.0015，R03 的容差是 0.0035。三条都没有相对容差。

按“先舍入再汇总”计算，结果是：网络类 13.691，非网络类 −11.545，合计 1.145。回归正例 `rounded_asset_aggregation.xlsx` 覆盖这种算法。

计算方法：实际净资本支出乘年末因子，再减去预测净资本支出。合计包括 Land。

## LLM 判据的分工

三条 LLM 判据的文字和权重没有改。模型答卷沿用当时保存的 LLM 判定。LLM 判据不和参考答案的文字比较，只对照随包输入。

| 判据 | 检查内容 | 不检查的内容 |
|---|---|---|
| L01 | 答卷引用的文件、页码、表格是否在输入中存在 | 来源是否为空（S03）；多出的记录（S05）；数值（R01–R03） |
| L02 | 答卷是否声称做过外部审计、实时查询或独立核验，但没有证据 | 没有对应的程序判据 |
| L03 | 答卷是否编造输入中没有的公司经营事实 | 数值错误（R01–R03）；来源定位（L01）；多出的记录（S05） |

## 程序负项（每条 −3）

| 判据 | 检查内容 |
|---|---|
| S01 | Results 前四列表头是 `label`、`value`、`unit`、`source_note`。比较时去掉首尾空格，大小写和顺序必须一致。后面可以加列。不符时扣分，并封顶 0.69。 |
| S02 | 每条必需结果的单位是 `AUD million nominal`。不符时扣分，并封顶 0.69。 |
| S03 | 每条必需结果的来源不为空，也不只是数字。不符时扣分，并封顶 0.69。 |
| S04 | 三条必需结果从第 2 行开始，按题面顺序排列。不得缺少、重复或颠倒。 |
| S05 | Results 不得多出带业务值、标签不在必需列表中的记录。违反时扣分，并封顶 0.69。重复的必需标签也扣分，但不封顶。 |
| S06 | 格式显示三位小数，或存储值等于舍入到三位的值。数值误差按各行容差另外检查。 |
| P01 | 已评分的结果单元格以外，不得有 Excel 错误值。 |

## 裁判读取校验

- 裁判必须先打开答卷。
- 裁判的每条理由必须引用答卷中存在的工作表和单元格。
- 程序能打开答卷、裁判却说读不到时，这次评分记为裁判错误。
- 裁判没有引用答卷单元格时，这次评分也记为裁判错误。
- 裁判错误的记录是 `verifier_error=1` 和 `judge:artifact_access_error`。裁判错误不算答卷分数，不进入一致性统计。
- 答卷引用的来源文件不存在时，这是答卷的错误。来源判据扣分，不记为裁判错误。

## 复现

运行 `python3 -B validation/run_regression.py`。这个检查覆盖正负例、分数合成规则、裁判读取校验和已保存的评分记录。它不调用求解模型和裁判。
